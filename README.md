# Upsure

Easy, reliable file uploads that resume after a disconnect. Built on the open [tus](https://tus.io) protocol.

> **Status: early development.** Nothing is published to npm yet and the packages below are empty placeholders.

## Packages

| Package | What it will be |
| --- | --- |
| `@tabalabs/upsure` | Framework-free upload client |
| `@tabalabs/upsure-react` | React hook and drop-in component |
| `@tabalabs/upsure-node` | Node upload server |

## Development

Requires Node 18+ and [pnpm](https://pnpm.io).

```sh
pnpm install
pnpm build
pnpm typecheck
pnpm test
```
